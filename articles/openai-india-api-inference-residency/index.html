OpenAI Moves Inference Inside India

On November 12, OpenAI announced API inference residency live in India, with first-wave support for the GPT-6 Luna model. Eligible request processing and model compute both happen inside India, at the price of a 10% regional premium and a zero data retention threshold.

WHAT HAPPENEDWhat Happened

On November 12, OpenAI announced that API inference residency is live in India, letting eligible enterprises and developers process supported AI requests inside the country. The first wave supports only the GPT-6 Luna model, through the Responses and Chat Completions APIs, going one step further than the India data residency option OpenAI already offered.

What moved in this time is compute, not just storage. Data residency previously governed only where customer content was stored; now, for supported workloads, request processing and the model compute that generates answers both happen inside India, and supported customer content is stored there too. India, Australia and Japan are the most recently added regions on OpenAI's inference residency map.

The scope is narrow for now. It covers direct API calls only and does not automatically extend to ChatGPT or other models, and OpenAI-hosted tools do not yet support regional processing in India. Access requires an organization to hold an approved, active zero data retention status; changing abuse monitoring alone is not enough. Customers create a new API project, select India for both storage and processing, and route supported requests through the India regional endpoint. Regional processing carries a 10% premium and supports standard pay-as-you-go only.

WHY IT MATTERSWhat Moved In Is Compute, Not Just Storage

For Indian enterprises, where AI processes information can decide whether an application can go into production at all. Nitin Bawankule, OpenAI's India enterprise head, said some Indian companies have held back from putting AI fully to work on important tasks because they needed the relevant information processed inside the country; local inference gives them more control. Customers with localization requirements, such as financial services, are the most direct beneficiaries.

The boundaries matter as much as the launch. The location commitment covers only supported workloads and in-scope customer content; billing information, usage statistics and some metadata may still be processed or stored outside India. OpenAI says enterprises can use it for text work such as summarizing documents, drafting replies and helping staff analyze information.

WHAT TO WATCHThe Localization Bill, Line by Line

Two things come next. First, whether inference residency expands from GPT-6 Luna to more models in India. Second, whether the 10% regional premium narrows as capacity grows. Similar residency capability recently appeared on some AWS Bedrock models, and before the India launch OpenAI already had the OpenAI for India initiative, including local partnerships.

For Indian enterprises going global, the bill is more than the premium. Zero data retention needs approval, only standard pay-as-you-go is supported, and hosted tools are not yet supported: added together, those terms decide whether local inference is a compliance solution or another hurdle.

SIGNAL JUDGMENT — ANALYSISInference Moved Inside India, and the Bill Rose With It

Tokenta Signal's judgment: the India residency launch moved compute inside the border, not just storage, the first time OpenAI's data residency has put model compute inside a national boundary too. For Indian enterprises with localization requirements, a real compliance threshold has been crossed. But thresholds remain: zero data retention needs approval, hosted tools are not yet supported, and regional processing costs 10% more. Whether localization pays will turn on whether the premium falls as capacity grows and when more models follow.

WHAT REMAINS UNCERTAINWhat Remains Uncertain

The 10% regional premium is the figure in OpenAI's documentation as reported by Dataquest India. The scope follows OpenAI's published terms: system data such as billing information, usage statistics and some metadata may still be processed or stored outside India. The first wave covers only GPT-6 Luna and direct API calls, not ChatGPT or OpenAI-hosted tools. This does not constitute investment advice.
