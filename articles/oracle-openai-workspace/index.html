Oracle Puts Enterprise Software Inside ChatGPT

Oracle announced on October 27 an expanded partnership with OpenAI: ChatGPT and Codex are built into Oracle's applications, data and cloud, with four new products led by AI Workspace, letting employees complete within-permission work across systems from a conversation.

WHAT HAPPENEDWhat Happened

On October 27, at its AI World conference, Oracle announced an expanded partnership with OpenAI: ChatGPT, Codex and OpenAI models are being built into Oracle's applications, data and cloud infrastructure, with four new products.

At the core is Oracle AI Workspace: employees describe a goal in ChatGPT, and plugins connect Fusion applications, NetSuite, the AI Database and OCI to find information across systems and complete approval workflows within organisational permissions. Oracle says existing governance rules, approval chains and access controls remain unchanged.

The other three products divide the work: AI Security Mesh uses OpenAI cybersecurity models to probe systems for vulnerabilities; App Composer uses Codex to build applications and deploy them to OCI; and the AI SMB Bundle packages ChatGPT Business, Codex and OCI credits for small and midsize businesses. Oracle disclosed that it already has 130,000 active ChatGPT users and 95,000 active Codex users internally.

THE NEW FRONT DOORThe Chat Box Becomes Enterprise Software's Front Desk

Employees used to hop between systems: an expense query in one application, a procurement approval in another. Workspace's premise is to turn conversation into the unified entry point, with system boundaries hidden behind plugins.

The key constraint is stated up front: being able to look something up is not the same as being able to approve it. An employee's role defines their action scope, and approvals still require human review. Convenience has not been bought at the cost of the permission structure, at least at the level of the announcement.

THE MARKETPLACE ROUTEThe Procurement Path: Resellers, Cloud Marketplaces and Universal Credits

U.S. Oracle customers can buy the OpenAI API, Codex and ChatGPT Work through Oracle Marketplace using eligible universal credits. Model procurement has entered an enterprise software vendor's own billing system for the first time.

For OpenAI, this means distribution: reaching, through Oracle's enterprise customer network, companies that would never sign an API contract directly. For Oracle, it means binding: AI capability becomes a value-added layer of its applications and cloud rather than an add-on.

THE COOPETITIONPartnership and Competition at the Same Table

Oracle is simultaneously OpenAI's cloud infrastructure partner, a chip buyer and an enterprise software channel. This round of cooperation compresses those three layers of relationship into one product suite: compute, models and applications.

An earlier report (Issue 61) covered OpenAI models landing on Google Cloud; this round, Oracle installs the same models inside enterprise software. The model makers' distribution war is moving from cloud shelves into the interior of business systems.

The next stop in the model distribution war is not the cloud shelf but the business systems employees open every day. Tokenta Signal's judgment is unchanged: whoever controls the workflow's entry point controls how models get used.
