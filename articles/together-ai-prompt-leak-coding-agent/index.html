A Coding Agent Handed Over the Repo Keys, and Client Prompt Samples Leaked

The leak did not start with a hacker breaking through defenses. An agent handed the keys over on someone's behalf.

KEY TAKEAWAYS
  • 01THE SAMPLES — Test prompt samples sit in a private repository.
  • 02THE COMMIT — A coding agent commits the repository credentials into a public codebase.
  • 03THE DOWNLOAD — An unauthorized party downloads the samples before the commit is pulled.

WHAT HAPPENEDWhat Happened

On November 21, 2026, Together AI disclosed a security incident. The company had collected prompt samples for routine software testing and stored them in a private Hugging Face repository; the samples came from requests to MiniMax M3, GLM-5.2 and Kimi K2.6 on June 24, July 4, July 8 and July 14.

While developing the public GitHub repository xorl, an AI coding agent committed credentials for that private repository into the public codebase. Automated scanning caught the exposure and pulled the commit, but within the exposure window an unauthorized party had already taken the credentials and downloaded the samples, then searched them for other services' credentials and tested each one.

Among the credentials tested were five canary credentials from a Dragos security experiment. Together AI says it found no further leakage beyond this incident, and the review of the sample contents is still under way; whether real customer sensitive information is involved has not been determined. The company has made zero data retention the default for new accounts and is working with an external forensics firm and law enforcement.

WHY IT MATTERSThe Canaries Sang First

Dragos had planted bait with unique links and credentials across about 2 million prompts, so any use of the bait proved someone had read the prompts. Five canary credentials were tested, which means the leak chain was caught in the act.

This is not an isolated incident. OpenRouter removed three providers in the same period and revoked zero-data-retention status from 125 endpoints. Once prompts leave a user's hands, their path is no longer decided by a privacy switch.

WHAT TO WATCHThe Default Has Changed

Together AI changed four measures after the fact: short-lived credentials, credential checks on all pull requests, zero data retention as the default for new accounts, and an updated AI coding-agent development process. The last one matters most: an agent's operating boundaries must be written into the process.

Affected customers should rotate any credentials and keys that appeared in prompts from June and July. The company says it will contact affected customers directly; until the review lands, any secret that appeared in a prompt should be treated as leaked.

THE SHIFTWhat Changed

FROM HUMAN COMMITS TO AGENT COMMITS
From Human Commits to Agent Commits
The credentials were not pasted in the wrong place by a person; an agent committed them while developing a public repository. Code review must cover every agent commit, and permission boundaries cannot rest on good behavior.
FROM REMEDIATION TO DEFAULT
From Remediation to Default
Zero data retention used to be an option; now it is the default for new accounts. Prompts that are never stored cannot be stolen, which works better than pulling a commit after the fact.

SIGNAL JUDGMENT — ANALYSISA Coding Agent Handed Over the Repo Keys, and Client Prompt Samples Leaked

Tokenta Signal's judgment: The leak did not start with a hacker breaking through defenses. An agent handed the keys over on someone's behalf. Give a coding agent write access with no boundaries, and the next thing it hands over may be more than credentials.

WHAT REMAINS UNCERTAINWhat Remains Uncertain

Whether the samples contain real customer sensitive information is still under review, and the company says it will contact affected customers directly. Beyond the five canary credentials, whether other real credentials were tested and confirmed valid has not been disclosed. Whether the three providers OpenRouter removed include Together AI has not been confirmed publicly by either side.
