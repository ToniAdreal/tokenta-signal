DeepSeek Takes Its Whole App Apart and Sells It as APIs

DeepSeek is selling its own app as parts: developers no longer need to assemble search, parsing, and voice themselves. The rival here is not the model itself but the middlemen who stitch scattered capabilities together for developers.

KEY TAKEAWAYS
  • 01THE LAUNCH — On November 13, DeepSeek opened the full capability set behind its app to developers, covering the Messages, Responses, and Chat Completions APIs.
  • 02THE TOOLS — Web search with multi-step deep search in thinking mode, link reading, file input for PDF, Word, PowerPoint, and images in plain text or rich layout, plus model safety checks.
  • 03THE MODEL — Applies to deepseek-flash, currently pointing at DeepSeek-V4.1-Flash-1017; the search and crawling APIs were opened first, on October 17.

WHAT HAPPENEDWhat Happened

The tool list comes in two layers. The first is built in, attached when calling the model: web search, link reading, file input, and safety checks. Search supports multi-step deep search in thinking mode; file input covers PDF, Word, PowerPoint, and images, with plain-text extraction or rich-layout parsing. The second layer is standalone: search, crawling, OCR, speech recognition, and speech synthesis each become their own API, billed separately per call or per unit.

Pricing is the most eye-catching part. Search and crawling cost the same: $0.75 per 1,000 successful requests. OCR is $0.225 per 1,000 pages. Speech recognition is $0.058 per hour and speech synthesis $0.225 per 10,000 characters, both at a limited-time 50% discount. The model is billed separately: deepseek-flash input at $0.30 per million tokens and output at $1.20, peak prices, halved off-peak.

Safety checks are another thread. Parameters screen the model's inputs and outputs, and risky content returns a rejection flag. DeepSeek requires developers serving the public to enable it; content moderation, model filing, and AI labeling remain the developer's own obligations. The company also open-sourced a browser demo chat client under the MIT license, which can import chat history exported from the app; keys and chats stay local, and it is clearly marked demo-only.

WHY IT MATTERSWhat Got Cheap Is Not the Model but the Assembly

For developers building AI apps, the time sink is often not tuning the model but stitching together search, parsing, and voice, then maintaining separate bills and quotas for each. DeepSeek hands over a whole working set at once, removing that assembly work.

The pricing strategy is equally direct: tool fees and token fees are separate, and low prices pull volume first. Speech recognition and synthesis are both at a limited-time 50% discount, with no stated end date, which is worth noting: the price on the bill may change later.

WHAT TO WATCHCompliance Duty Ships With the Interface

Two things come next. First, how fast developers actually adopt: the demo client lowers the trial barrier, but production requirements have not dropped at all. Second, how the safety check performs under real traffic: whether the rejection flag is accurate decides directly whether public-facing services can run stably.

What deserves closer attention is the division of responsibility. Content moderation, model filing, and AI labeling are named by DeepSeek as the developer's own duties. The easier the interface, the sooner that responsibility list should be read first: as capability opens up, compliance cost changes hands with it.

THE SHIFTWhat Changed

FROM APP TO API
From one app to a set of interfaces
Capabilities once available only by opening the app can now be called directly by developers. DeepSeek took its own product apart and turned it into parts for other people's products.
FROM TOKENS TO PER-USE FEES
From per-token billing to per-use billing
Tool fees and token fees are billed separately, with search, crawling, OCR, and voice each priced per call or per unit. The model itself continues to bill per token, with peak and off-peak prices differing by half.

SIGNAL JUDGMENT — ANALYSISThe Model Keeps Getting Cheaper; Capability Is Now Sold Separately

Tokenta Signal's judgment: what DeepSeek is selling this time is not a stronger model but a whole set of product capabilities that already work. Search, link reading, file parsing, and voice, once hidden inside the app, are now sold separately, billed per use. Prices are pressed low: search and crawling at $0.75 per 1,000 successful requests. For developers, the draw is not cheapness but no longer maintaining a pile of scattered services. The risk is equally visible: safety-check responsibility is pushed to developers, and public-facing services must clear content moderation, model filing, and AI labeling on their own.
