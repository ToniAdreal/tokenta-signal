营收1145亿还不够，苹果被内存涨价拖住了毛利

苹果11月2日公布2026财年第四季度财报，营收1145亿美元，同比增长12%，净利润307亿美元，新任CEO Ternus称内存价格形势前所未有，假日季毛利率指引降至45%到46%。

WHAT HAPPENED发生了什么

苹果在11月2日公布2026财年第四季度财报，营收1145亿美元，同比增长12%，净利润307亿美元，每股收益2.10美元。这是John Ternus在9月1日接替Tim Cook出任首席执行官之后的第一份财报。

iPhone业务贡献575.8亿美元，同比增长17%，创下9月季度纪录。Ternus称这是苹果有史以来最好的财年，全年营收4788亿美元，净利润1322亿美元。

财报的另一面是成本。Ternus在电话会上称内存价格形势前所未有，预计12月季度内存采购价继续上涨。首席财务官Kevan Parekh指引假日季毛利率为45%到46%，低于当季的47.9%，主要原因是内存成本与Siri AI的爬坡投入。

RECORD REVENUE, SQUEEZED MARGIN营收创新高，毛利却在往下走

1145亿美元这个数字本身没有问题，问题在它的构成。当季毛利率47.9%里约有1个百分点来自关税退税，扣掉这部分，毛利率环比实际下滑约1个百分点，主要就是内存。

假日季指引45%到46%，意味着下滑还要继续。苹果在6月与9月已经提过价，Mac与iPad价格上调、iPhone价格上调，都只抵消了部分压力。内存涨价的速度，超过了提价的速度。

MEMORY AS A TAX内存，成了全行业的共同账单

Ternus的原话是，内存价格形势前所未有，而且预计12月之后还会继续涨。苹果的库存从去年同期的57亿美元升到145亿美元，其中很大一部分就是提前囤的内存。

囤货只能缓一时。首席运营官Sabih Khan在电话会上表示，iPhone Duo的生产已经受限，Mac与iPad在假日季同样面临内存驱动的供应约束。便宜库存用完之后，成本压力会原样暴露出来。

TERNUS'S FIRST REPORT新CEO的第一份财报，先交了成本答卷

Ternus接任两个月，第一份财报的叙事是双面的。营收与iPhone纪录给了他开门红，内存与毛利率指引给了市场一个需要消化的现实。股价在盘后下跌约3%，说明市场先算了毛利账。

假日季指引的营收增长为7%到10%，对应1538亿到1581亿美元，仍可能是苹果历史上最高的季度营收。营收纪录与毛利下滑同时成立，这就是这份财报的完整面貌。

SIGNAL JUDGMENT卖得越多，内存税越重

Tokenta Signal 判断：苹果这份财报说明了一件事。AI基建抢内存的账单，正在传导到每一台消费电子产品上。营收纪录挡不住成本曲线。

WHAT REMAINS UNCERTAIN还有什么不确定

本篇的边界：1145亿美元与307亿美元为苹果官方财报数字。假日季毛利率45%到46%为公司指引，不是实际结果。关税退税对当季毛利率与每股收益的影响为公司口径，约1个百分点与0.05美元。
