OpenAI Brings Local API Processing to India, Starting With GPT-6 Luna

OpenAI announced on November 12, 2026 local processing and inference for its API in India, available initially for the GPT-6 Luna model through the Responses and Chat Completions APIs. For supported workloads, both the processing of an API request and the model computation that generates its response take place in India, extending existing data residency from storage to processing. Access requires approved, active Zero Data Retention status; the launch covers direct API usage only, not ChatGPT, and OpenAI lists a 10% premium for GPT-6 Luna regional processing.

WHAT HAPPENEDWhat Happened

OpenAI announced on November 12, 2026 that it has enabled local processing and inference for its API in India, giving eligible businesses and developers the ability to process supported AI requests within the country. The offering is available initially for the GPT-6 Luna model, through the Responses and Chat Completions APIs, and builds on OpenAI's existing data residency options in India.

The launch extends residency beyond where information is stored. Until now, data residency covered where customer content sat; for supported workloads, both the processing of an API request and the model computation that generates its response now take place in India, and supported customer content is also stored in country. OpenAI's API inference residency is available in other parts of the world, with the most recent additions being India, Australia and Japan.

The scope is narrow for now. The launch covers direct API usage and does not automatically extend to ChatGPT or other models, and OpenAI-hosted tools are unavailable for regional processing in India. Access requires an organisation to have approved, active Zero Data Retention status; modified abuse monitoring alone is insufficient. Customers start by creating a new API project with India selected for both storage and processing, and route supported requests through the India regional endpoint. OpenAI lists a 10% premium for GPT-6 Luna regional processing, and only standard pay-as-you-go processing is supported in India.

WHY IT MATTERSA compliance fix, not a blanket guarantee

For Indian organisations, where AI processes information can be a deciding factor in whether an application moves into production. That is especially relevant to customers in financial services with specific localisation requirements. Nitin Bawankule, OpenAI's Head of Enterprise for India, said some Indian businesses have not fully deployed AI for important work because they need the information involved to be processed within the country, and that local inference gives them more control over where supported workloads run.

The boundary matters as much as the launch. The location commitment applies to supported workloads and in-scope customer content; system data such as billing information, usage statistics and certain metadata may still be processed or stored outside India. OpenAI says businesses can use the capability for text-based work such as summarising documents, drafting responses and helping employees analyse information.

WHAT TO WATCHThe residency map, and the price of staying local

Watch whether OpenAI extends inference residency to more models in India beyond GPT-6 Luna, and whether the 10% regional premium narrows as capacity grows. The same residency capability was recently made available on certain models in AWS Bedrock, and the India launch follows OpenAI's earlier OpenAI for India initiative, which included a partnership with Tata Group to develop domestic AI data centre capacity.

The broader question is whether residency becomes a standard line item in regulated markets. India, Australia and Japan are the most recent additions; watch which region OpenAI names next, and whether rivals match the in-country processing offer rather than storage-only residency.

SIGNAL JUDGMENT — ANALYSISResidency now covers where the model thinks, not just where the data sits

Tokenta Signal's judgment: This is a narrow but useful fix for a specific compliance headache. Indian firms that could not move AI workloads into production because the processing happened elsewhere now have a path, starting with one model and one API surface. It is not a blanket India data guarantee: system data can still leave the country, other models are not covered, and there is a 10% premium for staying local. The test is whether GPT-6 Luna is the first model or the only one.
