OpenAI Sets Five Rules for Its Models, and Admits It Has Not Met Them Yet

On October 29, 2026, OpenAI updated the Model Spec, reorganising it around five values including faithfulness to human intent and reducing harm, while conceding that current models do not yet fully conform to the new version.

WHAT HAPPENEDWhat Happened

On October 29, 2026, OpenAI updated the Model Spec, the public document that sets out how it wants its models to behave. The new version no longer lists a long string of detailed rules; it is reorganised around five core values: be faithful to human intent, reduce harm, be honest and transparent, preserve human autonomy, and act with care.

Faithfulness to human intent ranks first. The model must understand who is giving the instruction, what they actually want, and how the current situation affects the goal, rather than taking literal instructions at face value. Where an instruction conflicts with safety rules or higher-level system guidance, the model should not comply.

The new version also adds two practical guidelines. Models may use memory and past conversations to infer a user's real intent, but must keep the user's own words separate from their inferences and state assumptions openly, so users can correct them. Agents executing tasks must not obstruct oversight, correction or shutdown, and must not pursue self-interested goals such as self-preservation.

VALUES BEFORE RULESFive Values Are, First of All, a Priority Order

The old Model Spec read like a manual; the new one reads like a constitution. A manual tells the model what to do in each situation; a constitution first settles who wins when values conflict. Faithful intent is the foundation, reducing harm is the hard constraint, and honesty and autonomy decide which way the model leans in grey areas.

That structure matters especially for agents. The more autonomously a model acts, the more impossible it becomes to write rules for everything. A value ordering gives the model a basis for cases the manual never covered, at the cost of making the judgments themselves harder to audit.

MEMORY, REGULATEDMemory Has Moved from Forbidden Zone to Regulated Tool

The new version allows models to use memory to infer intent, a clear shift. Before, every prompt was treated as an isolated request; now past conversations are legitimate material for understanding intent.

The conditions are equally explicit. Inferences must be open and correctable, and the user's words must not be blended with the model's inferences. When a user is comparing job opportunities, the model may draw on a previously mentioned preference for stable hours, but must surface that assumption. The value of memory depends on whether the user can change it at any time.

THE HONEST CAVEATAdmitting It Falls Short Is More Credible Than Claiming It Complies

The new version contains a key sentence: current models do not yet fully conform to the spec, and the company is still testing new training methods. That candour gives the document more weight. It is not a report card, it is a blueprint.

External verification remains the weak point. No independent test can show to what degree ChatGPT follows the five values, and disputes will concentrate on specific cases. The spec's significance lies not on publication day, but in whether it can be used as a yardstick in every future dispute.

SIGNAL JUDGMENT — ANALYSISThe More the Rules Read Like a Constitution, the Harder the Audit

Tokenta Signal's judgment: model behaviour standards are being upgraded from manuals to value orderings. That is necessary for the agent era, but values cannot execute themselves, and disputes will only multiply.

WHAT REMAINS UNCERTAINWhat Remains Uncertain

The boundaries of this report: the Model Spec is a target OpenAI has written for itself, not measured performance already achieved. OpenAI explicitly says current models do not yet fully conform to the new version, and outsiders cannot independently verify the degree of compliance. This does not constitute investment advice.
