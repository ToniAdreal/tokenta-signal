Claude自己动手，把接口从Python搬到Rust

Anthropic 工程师在 10 月 27 日播客中透露，Claude Messages API 已从 Python 单体全面切到 Claude 自己写的 Rust 版本，CPU 约省 40% 到 50%，首字时间快 10% 到 20%。

WHAT HAPPENED发生了什么

Anthropic 工程师在 2026 年 10 月 27 日的 Latent Space 播客中透露，Claude Messages API 已经全面切到 Rust 版本。原先的 Python 单体跑在单个谷歌云区域，CPU 效率很低，团队判断迟早会撞上 CPU 天花板。

选择 Rust 的时候，团队里几乎没有 Rust 程序员。人类负责设计分布式系统架构，Claude 负责写代码。团队先做了完整的 Rust 分支，用影子流量与 Python 系统逐项比对输出，确认一致后才切真实流量。

结果是纯移植，没有新功能。工程师给出的估算，是 CPU 节省 40% 到 50%，首字时间快 10% 到 20%。这组数字来自播客口头回答，不是正式基准报告，读的时候要按估算处理。

FIXED BUDGETCPU 是一笔固定预算，不是无限资源

工程师的说法很实在，CPU 是跟云厂商谈下来的固定预算，要在产品服务、智能体沙箱、持续集成与研究之间分配。智能体写代码越多，持续集成的运行次数越多，CPU 的缺口就越大。

让每次请求更便宜，比多买 CPU 更直接。Rust 的选择不是为了追新语言，是为了在固定预算里多跑请求。语言选型在这里是一道成本题，不是品味题。

SHADOW TRAFFIC影子流量，是这次移植真正的护栏

没有 Rust 程序员的团队敢重写核心接口，底气来自验证方法。完整分支加影子流量比对，等于让新系统先在真实流量上跑一遍影子考试，答错不影响用户，答对才放行。

这种方法论比语言本身更值得学。智能体写代码的规模越大，验证的权重就越高。写代码可以交给模型，判断新旧系统是否等价，必须有一套不依赖模型的比对机制。

SAME ROADGitHub 也在同一条路上

Anthropic 不是孤例。GitHub 在 9 月公布了 Copilot 智能体运行时从 TypeScript 迁移到 Rust 的做法，同样由智能体主导编写，同样有细到 token 账单的收益核算。两家公司的共同点，是把智能体当作重写工具，而不是演示工具。

区别在证据的完整度。GitHub 给出了可核查的账单，Anthropic 目前只有播客里的估算。智能体编码的叙事正在从能不能写，转向写完之后省了多少钱，证据标准也在同步提高。

SIGNAL JUDGMENT智能体写代码，验证才是真正的工程

Tokenta Signal 判断：这次移植的亮点不是 Claude 会写 Rust，是没有 Rust 程序员的团队敢用影子流量验货。智能体编码的门槛，正在从写代码转向验代码。

WHAT REMAINS UNCERTAIN还有什么不确定

本篇的边界：CPU 节省 40% 到 50%、首字时间快 10% 到 20%，都是工程师在播客里的口头估算，不是已发表的基准测试。移植本身没有新功能，代码由 Claude 写，人类负责系统设计与验证，影子流量的比对结果没有公开细节。
