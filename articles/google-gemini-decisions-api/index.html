Google's New Model Only Answers Multiple Choice. It Does Not Write.

Google released the Gemini Decisions API on November 11, powered by the new Gemini Decision 1 model. A single request can answer up to 1,000 questions in parallel against the same multimodal input, returning probabilities and confidence scores, with zero output tokens.

WHAT HAPPENEDWhat Happened

The Gemini Decisions API is not a chat model. A single request can answer up to 1,000 questions in parallel against the same multimodal input: yes-or-no, multiple-choice and scored questions all work.

Input can be text, images, audio, video or PDF, up to 256K tokens. A single forward pass returns probabilities and confidence scores, with zero output tokens.

End-to-end latency runs 150 to 250 milliseconds, with the model computation taking 50 to 100 milliseconds. Pricing is $0.10 per million input tokens, output is free, and a free tier is available.

NO WORDSA Model That Does Not Write, Only Chooses

A large model's output used to be text, and text needs parsing, verification and hallucination checks. The Decisions API collapses output into probabilities and scores that machines can use directly.

The design targets bounded decision scenarios: tool selection, policy checks, model routing, context scoring. The more structured the answer, the better it fits a program.

1000 IN ONE PASSA Thousand Questions, One Forward Pass

Answering 1,000 questions in parallel is the API's most counterintuitive feature. The traditional approach makes one call per question, with cost and latency growing linearly.

One forward pass producing 1,000 scores changes the cost structure. For decision-dense work, such as scoring a thousand pieces of content, a cheap way to do it exists for the first time.

V1BETA ONLYAPI First, Vertex to Follow

The launch runs on the Gemini API's v1beta endpoint and Google AI Studio; Vertex AI support is marked coming soon, with no date.

By the day after launch, integrations from OpenRouter, LangChain, Vercel and LiteLLM were already in progress. Fast ecosystem pickup is a sign the demand is real.

THE SHIFTWhat Changed

FROM TEXT TO SCORES
From chat answers to structured decisions
Model output converges from free text into probabilities and scores that programs can consume directly. Decision scenarios have a native model interface for the first time.
FROM OUTPUT TO INPUT PRICING
From charging for output to charging for input
Zero output tokens means output is free; the bill only counts input. For decision-dense work, the cost model changes completely.

SIGNAL JUDGMENT — ANALYSISGoogle's New Model Does Not Write, It Only Chooses

Tokenta Signal's judgment: the Decisions API is another step in Google pulling models out of the chat box. Text output is expensive and hard to verify; probability output is cheap and machine-readable. One forward pass for 1,000 questions targets decision-dense real-world work. One mark against it: the benchmark charts come as images with no scores to check.

WHAT REMAINS UNCERTAINWhat Remains Uncertain

The performance and calibration advantages appear only as charts in the official post, with no publicly verifiable scores. Context caching, Batch API and Flex or Priority inference are not yet supported; the API is limited to the v1beta endpoint. Vertex AI support is marked coming soon, with no date.
