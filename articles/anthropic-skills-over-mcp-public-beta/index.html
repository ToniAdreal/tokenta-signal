Anthropic Ships Skills over MCP as the Standard Turns Two

Anthropic announced on November 24, 2026 that Skills over MCP is now in public beta in Claude and Claude Code, letting MCP servers publish skills alongside their tools so Claude can take on longer, multi-step work. The beta is on by default for Pro, Max and Ultra plans, available to Team plans once an admin enables it, and coming soon to Enterprise. Tasks and Elicitation are now generally available in Claude and Claude Code for Pro, Max and Ultra plans, rolling out to Team and Enterprise organizations, and File Uploads is rolling out soon. The updates arrive as the Model Context Protocol turns two: Anthropic launched MCP on November 25, 2024, and the standard now sees over 700 million monthly SDK downloads, with more than 10,000 MCP connectors for Claude.

WHAT HAPPENEDWhat Happened

Anthropic announced on November 24, 2026 that Skills over MCP is now in public beta in Claude and Claude Code, so MCP servers can publish skills alongside their tools and guide Claude through longer, multi-step work. Claude loads a skill only when it is needed, keeping context use low, and skills update with the server, so developers can ship tools and guidance together and users have nothing separate to install.

The same announcement made Tasks and Elicitation generally available in Claude and Claude Code. Tasks lets a server run a time-consuming operation, or even a full agent loop, in the background while Claude keeps working and picks up the result when it is ready. Elicitation lets a server pause mid-call to ask the user for input through a form or link, then continue where it left off. File Uploads, which passes PDFs, spreadsheets and images to a server without routing them through the context window, is rolling out soon.

The updates arrive as the Model Context Protocol turns two. Anthropic launched MCP on November 25, 2024 as an open standard for connecting AI agents to the systems where data lives. The protocol now sees over 700 million monthly SDK downloads, and there are more than 10,000 MCP connectors for Claude. MCP is hosted by the Agentic AI Foundation and shaped by the maintainers, contributors and developers who build on it.

WHY IT MATTERSSkills turn a server into a colleague.

Tool names and descriptions tell Claude what a server can do, but they do not cover how to handle specific use cases. Skills close that gap: a server can now ship best practices, step-by-step workflows, or playbooks tailored to a user's account or organization, and Claude follows them as part of the job rather than guessing from a tool list.

The launch partners show the range. Shopify helps Claude design and update a merchant's online store end to end, HubSpot onboards customers and gets them set up in Claude, Atlassian draws on deep organizational context for insights and work analysis, and Carta will help Claude draft and issue equity from an uploaded document. The skill, not the tool call, is what makes the agent useful here.

THE SECOND MOVEBackground work is the real agent test.

Agents in production are taking on longer, more consequential jobs, and the Tasks and Elicitation releases are built for exactly that. ZoomInfo uses Tasks to run deeper accounts and contact research that previously took several prompts. Supabase confirms costs before creating a paid project or running destructive SQL, Railway asks before removing a service, and GitHub has users enter a repository name before an agent deletes it.

The pattern is consistent: as agents gain the power to spend money and delete things, the protocol is building in the pause button first. Elicitation is the guardrail that makes the autonomy credible, and File Uploads, coming soon, removes the last awkward step of forcing files through the model's context window.

THE SHIFTWhat Changed

FROM TOOLS TO PLAYBOOKS
From tools alone to tools plus playbooks
MCP servers used to expose only tools, and Claude had to infer how to use them from names and descriptions. Skills over MCP lets a server ship the workflow itself, so Claude follows the server's own procedure for multi-step work instead of improvising one.
FROM CALLS TO DELEGATION
From one-shot calls to long-running delegated work
Tool calls used to have to finish before Claude could move on. Tasks lets a server run a long job or a full agent loop in the background, Elicitation pauses for user sign-off mid-call, and File Uploads moves files without the context window. The protocol now treats a server as a delegate, not a function call.

SIGNAL JUDGMENT — ANALYSISThe protocol grows up from plumbing to procedure.

Anthropic is moving MCP from how to call a tool to how to do the job. Skills are the more important half of this release: a server that can hand Claude its own playbook, and update it without anyone reinstalling anything, turns an integration into a working relationship. The 700 million monthly downloads say the standard has already won distribution. The open question is whether server-supplied skills make agents genuinely better at multi-step work, or simply better at following somebody else's script. The Elicitation piece is the quiet tell. As agents take on consequential actions, the protocol is building in the pause button first, and that is what will decide whether enterprises trust it with real work.
