700 Intranet Capabilities, Plugged Into Enterprise AI Assistants at Once

Interact Software released Interact MCP on October 26, a Model Context Protocol server that opens the intranet's existing 700 capabilities to authorised AI assistants, covering 26 intranet areas and compatible with Claude, ChatGPT, Microsoft 365 Copilot and Gemini Enterprise.

WHAT HAPPENEDWhat Happened

Interact MCP is positioned as a Model Context Protocol server: it opens the intranet's existing 700 capabilities to authorised AI assistants. Coverage spans 26 intranet areas, from content and communications to community and analytics. Employees act with their own existing permissions; the assistant gains no rights beyond the employee's own.

Use cases split by role: employees can find policies by source link; communications teams can update pages; platform leads can compare adoption across groups. The same capability set becomes different workflows in different roles' hands.

THE PERMISSIONSMCP's Selling Point Is That Permissions Do Not Change

The most common sticking point in enterprise AI rollouts is not model capability but permissions: what an assistant can see and what it can change. Interact MCP anchors permissions to the employee; the assistant inherits the employee's existing rights and opens no new doors.

That design hands security responsibility back to the company's existing permissions system. The assistant is not a new privileged account but a tool that walks along existing permissions, with auditing and revocation following the original mechanisms.

THE NUMBERThe 700 Figure Needs to Be Read in Parts

The 700 capabilities are not new features. They are the existing capabilities of the Cue and Conductor products opened through the protocol. The figure's significance is reach, not novelty: functions that once required clicking through the intranet interface can now be invoked in an assistant conversation.

For buyers, coverage is what needs verifying: whether their own high-frequency scenarios are among the 26 areas, and what the assistants' success rate is when calling them. The announcement gives the total, not a per-area availability list.

THE TWO-WAY LINKThe Connection Runs Both Ways

The other half of the announcement is often overlooked: Conductor can also connect outward to MCP-supporting external systems, including Workday and SAP. The link between intranet and business systems becomes two-way, and an assistant can pull data from external systems inside the intranet.

Two-way connection brings value and risk as a pair: workflows become more complete, and the permission boundary more complex. Before switching it on, companies need to confirm that external systems' permissions likewise follow the employee's own authorisation scope.

SIGNAL JUDGMENT — ANALYSISAn Assistant's Ability Depends on What It May Legitimately Touch

The Interact MCP release states the enterprise AI contest plainly: models can be generic, but data and permissions cannot. Tokenta Signal's judgment is unchanged: the next threshold for enterprise AI is not model parameters, but whether a permissions system can be safely inherited by an assistant.
